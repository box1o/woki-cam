# RTL8211F-CG 3D models

- `RTL8211F_C187932.wrl`: existing visual model, with source and attribution
  recorded in [the model source inventory](../../../documentation/board-1/model-download-sources.json).
- `RTL8211F_C187932.step`: repository-generated nominal MCAD model, based
  independently on Realtek JATR-8275-15 revision 1.4, [§11 and §11.1](../../../datasheets/rtl8211f.pdf#page=68).
  It models a 5 × 5 × 0.85 mm QFN body, forty 0.20 mm wide / 0.40 mm pitch
  terminals, and a 3.70 × 3.70 mm exposed pad. It does not reuse or convert
  the VRML mesh. Undimensioned cosmetic markings are not represented.

KiCad uses the original WRL for rendering and locates the same-basename STEP
when exporting an assembly with model substitution enabled. The PCB footprint
and model placement do not change.

To regenerate, run [the generator](../../../scripts/generate_rtl8211f_step.py)
with a Python interpreter that can import FreeCAD and Part, for example:

```sh
PYTHONPATH=/usr/lib/freecad/lib /usr/bin/python3 scripts/generate_rtl8211f_step.py
```

# reference evidence

The active design is now implemented in `../../../boards/01-power/power.kicad_sch`. Use `../review.md`, `../components.csv`, `../connections.csv` and `../../board-1-custom.pdf` for current results.

This folder retains source CAD pin mappings, downloaded datasheet provenance, earlier planning records and historical PDF previews. Baseline/component-plan files describe the earlier selection stage; they are not the active BOM. `poe-source-pins.json` stores native reference coordinates for connectivity comparison, not current schematic positions.

Official reference: https://www.ti.com/tool/PMP22477 . Original PDF documents are in `../../../datasheets/references/`.
